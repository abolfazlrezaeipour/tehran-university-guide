# 🎓 راهنمای نودانشجوی دانشگاه تهران

یک لندینگ‌پیج تک‌صفحه‌ای، مدرن و Responsive برای معرفی تجربه‌های روزهای اول دانشگاه به دانشجویان جدید دانشگاه تهران.

این پروژه با هدف انتقال تجربه‌های کاربردی و غیررسمی طراحی شده؛ نه جایگزینی برای سایت یا سامانه‌های رسمی دانشگاه.

> برای تاریخ‌ها، قوانین و اطلاعیه‌های متغیر، همیشه منابع رسمی دانشگاه تهران را بررسی کنید.

---

## ✨ ویژگی‌ها

- طراحی **Single Page Landing**
- رابط کاربری مدرن با تم **آبی آسمانی**
- پشتیبانی کامل از **Light Mode / Dark Mode**
- طراحی **RTL** و مناسب زبان فارسی
- Responsive برای موبایل، تبلت و دسکتاپ
- Navigation چسبان و تشخیص بخش فعال
- انیمیشن ورود بخش‌ها هنگام Scroll
- کارت‌های مدرن با Glassmorphism
- چک‌لیست تعاملی ماه اول
- ذخیره وضعیت چک‌لیست در `localStorage`
- بدون Framework و وابستگی پیچیده
- ساختار ساده و قابل توسعه با HTML / CSS / JavaScript

---

## 🧭 بخش‌های سایت

سایت شامل بخش‌های اصلی زیر است:

1. **شروع**
   - خوش‌آمدگویی به دانشجوی جدید
   - معرفی کوتاه سایت
   - لینک سامانه‌های رسمی

2. **هفته اول**
   - کارهای قبل از اولین کلاس
   - وسایل داخل کیف روز اول
   - پیشنهاد پوشش مناسب

3. **کلاس و معدل**
   - اهمیت جلسه اول
   - خودخوانی در دانشگاه
   - استفاده از تجربه سال‌بالایی‌ها
   - چند عادت ساده برای ترم اول

4. **زندگی دانشجویی**
   - دوست‌یابی
   - اعتماد و حفظ حریم شخصی
   - انجمن‌ها و فعالیت‌های دانشجویی
   - ارتباط با استاد
   - میان‌برهای کوچک دانشگاه

5. **خوابگاه قدس ۳**
   - وسایل ضروری
   - قوانین کاربردی اتاق
   - امنیت وسایل
   - غذا و آشپزخانه
   - دلتنگی و سازگاری با خوابگاه

6. **چک‌لیست ماه اول**
   - ۱۰ مورد تعاملی برای پیگیری شروع ترم

## 🚀 اجرا

برای اجرای پروژه نیاز به نصب Node.js یا هیچ ابزار Build خاصی نیست.

کافی است پروژه را Clone یا Download کنید و فایل زیر را در مرورگر باز کنید:

```text
index.html
```

یا برای تجربه بهتر در توسعه، پروژه را با یک Local Server اجرا کنید.

مثلاً با VS Code و افزونه **Live Server**.

---

## 🌙 Dark Mode

حالت تاریک با استفاده از CSS Variables پیاده‌سازی شده است.

تم انتخاب‌شده کاربر در مرورگر ذخیره می‌شود و در مراجعه بعدی نیز حفظ خواهد شد.

کلید تغییر تم در Header قرار دارد.

---

## ☑️ چک‌لیست تعاملی

وضعیت موارد چک‌لیست ماه اول در `localStorage` ذخیره می‌شود.

بنابراین اگر کاربر صفحه را Refresh کند، تیک‌های قبلی باقی می‌مانند.
